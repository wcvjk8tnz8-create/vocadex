# Vocadex

**Vocadex** is an English vocabulary and exercise platform built for the students of
**P.L.K. Siu Hon Sum Primary School** (保良局蕭漢森小學 · `plkshs.edu.hk`).

It looks and plays a little like Duolingo: short, cheerful exercises, chunky buttons,
streaks of encouragement — but every question is generated from the Hong Kong
primary English curriculum.

---

## Highlights

| | |
|---|---|
| **Stack** | Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 |
| **Look** | Frosted-glass panels (`backdrop-filter: blur()`), warm accent colours — **no blue-violet gradients** |
| **Type** | English: `Momo Trust Sans` → `Comic Sans MS`. Chinese: 楷體 (KaiTi) → 宋體 (SimSun) |
| **Curriculum** | **Primary Longman Elect** only — P1–P6 × Term 1 / Term 2, each unit with vocabulary, sentence patterns, a passage and reading questions |
| **Sign-in** | Every student has a **6-character password** generated by the teacher |
| **Teacher** | `/teacher` is protected by a server-checked key |
| **Levels** | easy · medium · hard · extremely hard · impossible |
| **Energy** | Max 100 · **−2 taken each time you answer one question** (not all at once) · **+50 every 12 hours** |
| **Sign-in** | Class number only (e.g. `211B0000`), a personal password, or a **scanned class QR code** |
| **Rewards** | Score **90%+** in a Unit Exercise → level up + a **real mystery gift**, and the teacher is notified automatically |

## Deploy to Vercel

1. Push this repository to GitHub (already done), then
   **vercel.com → Add New → Project → Import** `wcvjk8tnz8-create/vocadex`.
2. Framework preset is detected automatically (**Next.js**) — keep every default.
3. Add the environment variables (Project → Settings → Environment Variables):

   | Name | Value |
   |---|---|
   | `TEACHER_KEY` | the password teachers type on `/teacher` (e.g. `plkshs`) |
   | `UPSTASH_REDIS_REST_URL` | from console.upstash.com |
   | `UPSTASH_REDIS_REST_TOKEN` | from console.upstash.com |

4. **Deploy.** Vercel builds with `npm run build` and serves the App Router routes
   together with the `/api/gifts` and `/api/progress` serverless functions.

> **Important:** Vercel's file system is read-only. Without Upstash, gift requests
> are kept in the memory of whichever instance happens to serve the request, so they
> can disappear between requests. The free Upstash tier is more than enough for a
> whole school — connect it before going live.

### Going live checklist

- [ ] Set a real `TEACHER_KEY` and share it with the English panel only
- [ ] Connect Upstash Redis
- [ ] Visit `/teacher`, enter the key and confirm the dashboard loads
- [ ] Try a unit test at 90%+ on a student account and confirm the request appears

## Cloud back-end (mystery-gift notifications)

Students and teachers share the same Next.js server, so no extra service is needed.

| Route | Who | What |
|---|---|---|
| `POST /api/auth` | student | checks the email + password before sign-in |
| `POST /api/gifts` | student | uploads a gift request when a unit test scores 90%+ |
| `GET /api/gifts` | teacher | lists all requests |
| `PATCH /api/gifts` | teacher | marks a gift `given` / back to `pending` |
| `POST /api/teacher/session` | teacher | swaps the teacher key for a 12-hour session token |
| `GET /api/teacher/session?token=…` | teacher | checks whether a session is still valid |
| `GET /api/students` | teacher | class list with every student's password |
| `POST /api/students` | teacher | add emails (passwords generated) or reset one password |
| `PATCH /api/students` | teacher | set a password by hand |
| `DELETE /api/students` | teacher | remove a student |
| `POST /api/progress` | student | syncs profile, energy and unit records |
| `GET /api/progress?email=…` | student | syncs back down on another device |

Passwords are never returned to a student's browser — only the teacher endpoints
(protected by the key or a session token) include them.

Storage (`src/lib/server/db.ts`) picks one of two back-ends automatically:

1. **Upstash Redis REST** — set `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN`.
   Free tier is plenty, and it works on Vercel / Netlify / any serverless host.
2. **Local JSON file** — `.data/vocadex.json`, for any ordinary Node server.

```bash
# .env.local
TEACHER_KEY=plkshs
UPSTASH_REDIS_REST_URL=
UPSTASH_REDIS_REST_TOKEN=
```

Without any environment variables the app still works fully offline: progress is kept
in `localStorage` and gift requests queue locally, then upload as soon as the server
is reachable.

Students also **sync down on sign-in**: `/api/progress?email=…` returns their saved
profile, energy and unit records, so signing in on a school computer or at home keeps
the same unit level and the same energy — a fresh device never gets a free refill.

## Sign-in and passwords

### Three ways in

1. **Class number** — type `211B0000` and press **Let's Go!**. Vocadex adds
   `@plkshs.edu.hk` for you and works out the display name (`211B0000`).
2. **Personal password** — a 6-character code such as `K7M2Q9`, set by the teacher.
3. **Class QR code** — the teacher generates a code on `/teacher`, and the class
   scans it. No typing, no password.

### Using the class QR code

1. Teacher: `/teacher` → **QR sign-in** → choose a label and how long it lasts →
   **Generate**. A QR code appears on the board.
2. The QR contains **only the plain token text** (e.g. `SUN-4821`) — it is not a URL.
3. Student: open Vocadex → type the class number → tap **Scan QR** → point the
   camera at the board → signed in.
4. The dashboard shows the countdown and how many students have signed in.



- The teacher opens `/teacher`, signs in with the teacher key, and goes to the
  **Students** tab.
- Paste the class emails (one per line). Vocadex generates a **6-character password**
  for each student, e.g. `K7M2Q9` — no `O/0` or `I/1`, so nobody misreads it.
- Export the list as CSV or print it and hand each child their password.
- A student who is already signed in on a device stays signed in — they are never
  asked to retype anything.
- Students not yet on the class list can still sign in the first time; they then
  appear in the dashboard and the teacher can generate their password.
- `New` gives a student a fresh password (use it if a password is shared around).

If the teacher key is rejected, the response says whether `TEACHER_KEY` is actually
configured on the server — the usual cause is adding the variable and forgetting to
**Redeploy**.

## Curriculum data

Words live in two plain data files, so teachers can edit them directly. The whole
app follows **Primary Longman Elect** (Pearson) only:

- `src/lib/data/lower-primary.ts` — P1–P3
- `src/lib/data/upper-primary.ts` — P4–P6

Each unit follows the EDB *English Language Education Key Learning Area Curriculum
Guide (Primary 1–6)* and the themes used by mainstream textbooks
(Longman Elect / Oxford New Magic / PLPR-W), for example:

**Primary 6 follows Longman Elect (2nd Edition) chapter by chapter:**

| Term | Unit | Longman Elect | Topic | Grammar |
|---|---|---|---|---|
| T1 | 1 | 6A Ch.1 What Do You Want to Be? | Jobs | want to be … because … / If I become …, I will … |
| T1 | 2 | 6A Ch.2 The Best Person for the Job | Job requirements | need to be + adj / so / so that |
| T1 | 3 | 6A Ch.3 Problems Around Us | Natural disasters | since / too + adjective |
| T1 | 4 | 6A Ch.4 We Can Make a Difference | Charity | either … or / Shall we …? / neither … nor |
| T1 | 5 | 6A Ch.5 Fun with Stories | Story characters | relative pronouns who / which |
| T1 | 6 | 6A Ch.6 Story Phrasal Verbs | Phrasal verbs | come up with, give up, set off … |
| T2 | 1 | 6B Ch.1 Festivals Around the World | Festivals | the present passive |
| T2 | 2 | 6B Ch.2 Amazing Places | Landmarks | famous for / the past passive / where |
| T2 | 3 | 6B Ch.3 Save Our Planet | Pollution | so many / so much / stop + gerund |
| T2 | 4 | 6B Ch.4 Endangered Animals | Animals in danger | Therefore / unless |
| T2 | 5 | 6B Ch.5 Memorable Experiences | Experiences | gerunds / adjectives with prepositions |
| T2 | 6 | 6B Ch.6 Moving On | Consolidation | revision of all tenses |

P1–P5 units carry a `Longman Elect 1A Ch.1`-style label and use theme vocabulary
for those levels; swap in the school's own word lists whenever the books arrive.
Replace these with the school's own textbook word lists at any time — the exercise
generators read whatever is in these files, so no other code needs to change.
